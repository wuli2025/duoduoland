# 第8轮验收记录

本轮加入恋爱交友模式及专门的fitReason，保留原API、Bonjour视觉、file入口和公开投影边界。

## 实现与隐私

- 78人补齐虚构性别/出生年份；24位单身且明确开放者（男女各12），主要在休闲活动使用交友版。其余54人不入选。林知夏默认关闭；旧存储及旧恋爱文本迁移不自动授予公开或本场同意。
- 本场设置第2步可开启/拒绝；开启只授权当前场次，切到职业版本或隐藏必要字段即不满足交友条件。双方单身/公开/同意、目标性别年龄与反向偏好在本地及服务端重复检查。
- 交友独立权重：共同兴趣、生活节奏、价值观、城市、年龄和本场意图；职业权重0。无效年龄范围不放宽；否定恋爱、面向对象等技术语句不误入交友。
- Top列表和右侧详情有性别/意图适配的理由标题。fitReason最多60字，要求双方公开生活证据；禁外貌、财富/职级、物化与保证性措辞；联系方式脱敏；不合格逐条回退并记录。职业模式无fitReason。
- 页面请求快照纳入当前公开授权；离开本场设置/换步骤取消意图请求，避免过期解析占满精排并发槽。

## 真实评测

- 本地 3/3、真实模型 3/3，均100%；fitReason回退 0 条、全部理由回退 0 条、丢弃 0 条。
- AI之夜返回2位合格男性；城市徒步返回5位男性（符合双向条件总数11）；男性看展画像返回5位女性（符合双向条件总数10）。性别、单身、同意、25–35岁、共同兴趣、公开证据、措辞和降序检查全部通过。
- 最终3次评测请求用时8747 / 26728 / 32281 ms；详细Top列表、检查和请求号见[match-eval](match-eval.md)，每场景原始结果与安全日志见[round-8评测目录](evals/round-8/)。
