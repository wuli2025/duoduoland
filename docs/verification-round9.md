# 第9轮验收记录

## 实现

- 前端意图合并用本地恋爱关键词保护mode/目标性别/明确年龄；旧接口无mode或冲突性别不能把找男朋友切回职业匹配。service与matcher在rank前核对原文，结果再做双向/性别断言式过滤；客户端失败回退也排除错误性别。
- `appVersion=9.0.0`集中在config/llm，health返回启动时固定的版本。旧进程不会因为静态文件更新而冒称新版；缺版本也算不一致。设置/匹配页提示重启，dating只用本地。
- 首次/未设置活动为空，预报名AI之夜也为空；保留用户自己已保存的设置。空意图不重排，提示写一句或点选。
- 常见标签只读本场公开投影，每人每字段标签去重、按人数降序取16项；相同文字的行业/技能胶囊注明类型。职业与交友模式切换，交友仅统计本场公开且开启者。
- 点选/移出同步意图与预览；角色/行业/技能、兴趣/生活/价值观进入各自字段。删除性别/年龄同时修改原文，避免重新解析回来。
- 8套本地fitReason模板，按双方公开兴趣、生活、价值观、城市、年龄组合；最终本地Top5避免模板复用，仍校验60字/证据/禁用词。
