# 第 10 轮：品牌改名「多多群岛」+ 文字更大更饱满 + 首页轮播改为活动行式居中轮播
保持全部既有约束（≤500 行、配置化、无 emoji / 无 AI 味元素、隐私投影、不打印 .env.local 的 Key、不结束其他占用端口的进程；用户 8787 服务窗口由 Claude 重启，你验收用自己的实例）。整体视觉仍保持现在的 Bonjour 式克制风格（暖白底、黑字、亮黄点缀）。

## 1. 品牌改名
- 品牌名统一改为「多多群岛」：顶部 Logo、页脚 Logo 与"关于 多多群岛"、页面 <title>、名片卡片左上角的品牌字样（原 "bonjour!"）、分享链接示意域名、README、copy 中所有出现 Bonjour/bonjour 的用户可见文案。只改配置（config.app.brand 等）与引用处，不要在页面里硬编码。
- Logo 设计：中文字标「多多群岛」，字重 800–900，字距略收紧；可在字后加一个亮黄小圆点或用简洁线性 SVG 小岛形符号（克制、不要卡通、不要 emoji）。英文副标可选（如 DUODUO ISLANDS，小号字距拉开）。
- 名片卡片左上角改为「多多群岛」小字标；右上角 "HELLO, NICE TO MEET YOU." 可保留或改为中文"很高兴认识你"，统一风格。

## 2. 文字更大、更饱满
- 全站基础字号上调：正文从约 13–14px 提到 15–16px；辅助小字（灰色说明、标签、元信息）最小不低于 13px；标题层级相应放大（页面主标题约 48–56px，区块标题 26–30px，卡片标题 18–20px）。
- 字重更饱满：正文 400→450/500（字体支持时），标题 800；灰色说明文字颜色适当加深（对比度 ≥ 4.5:1）；行高 1.6–1.75。
- 统一调整 CSS 变量（字号/字重/颜色 token），不要逐处硬改；检查所有页面（活动、详情、本场设置、匹配、发现、找工作、我的名片、⌘K、现场大屏）没有因字号变大导致溢出、截断、换行难看、按钮挤压；1440 与 1024 宽度都检查。

## 3. 首页顶部轮播：改为活动行式居中轮播（参考图 docs/reference/huodongxing-carousel.png，已随消息附上）
- 结构：轮播上方一行居中的文字切换标签（如「精选 / 本周 / 榜单」，配置化；当前项黑色加粗下划线），切换时轮播内容随之变化（来自真实活动数据：精选=编辑推荐，本周=本周日期内，榜单=报名人数排序）。
- 轮播：中间一张大图居中且最高（约容器宽 50–55%，16:9 或 2.1:1），左右各露出相邻活动的大部分（略矮、略暗），整体呈"中间突出、两侧露边"的层叠效果；左右两侧大号细线箭头（线性 SVG，克制），下方居中圆点指示器（当前点为黑色或亮黄长条）。
- 每张幻灯片使用活动封面图（assets/img/events 与 bg/hero*），在图片左下或左侧叠加活动信息：标题（大号粗体）、日期时间、地点、报名人数，以及「立即报名 / 查看详情」按钮；保证文字可读（底部渐变遮罩，克制，不要霓虹）。
- 交互：5 秒自动轮播、鼠标悬停暂停、点击两侧露出的卡片或箭头切换、键盘 ←/→、触控/拖拽滑动；过渡平滑（transform + 透明度，约 450ms，ease-out）；prefers-reduced-motion 时关闭自动播放与动画。无限循环。
- 保留轮播上方的"正在进行"提醒条（「你报名的「AI Agent 开发者之夜」正在进行 · 查看 Top 5 →」）。原来右侧两张小推荐卡可移除或移到轮播下方，以轮播为主视觉。
- 轮播组件独立成模块（例如 src/ui/carousel.js + assets/css/carousel.css），通过参数接收幻灯片数据，便于复用；写测试覆盖索引循环、标签切换数据源。
