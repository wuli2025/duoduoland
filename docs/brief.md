## 0. 硬性约束（必须遵守）

1. **双击 `index.html` 即可打开运行**（file:// 协议）。因此**不要用 ES module / fetch 本地 JSON**；使用普通 `<script src>` 按顺序加载，所有模块挂在 `window.BJ` 命名空间下（`BJ.config`、`BJ.data`、`BJ.matcher`……）。不依赖任何 CDN 和网络。字体用系统字体栈：`"PingFang SC","HarmonyOS Sans SC","Microsoft YaHei",system-ui`。
2. **每个自有代码文件 ≤ 500 行**（含空行注释，接近 400 行就拆）。按职责拆文件，禁止压行。
3. **配置化**：品牌名、导航项、页面文案、主题色、推荐权重、城市列表等放 `src/config/*.js`；业务模块通过参数接收配置，不在页面代码里硬编码。演示数据放 `src/data/*.js` 并在文件头标注 `// DEMO DATA`。
4. **模块分层**：`src/config`（配置）/ `src/data`（模拟数据）/ `src/core`（matcher 推荐引擎、store 状态与 localStorage、router 哈希路由）/ `src/ui`（components 通用组件、pages 各页面）/ `assets/css`（按页面拆分的样式，类名带页面前缀避免污染）。
5. **推荐引擎 `src/core/matcher.js` 必须同时能在浏览器和 Node 中运行**（UMD：`if (typeof module!=='undefined') module.exports=...; else window.BJ.matcher=...`），并在 `tests/matcher.test.js` 用 `node --test tests` 写有意义的测试（双向意图加成、隐私字段不参与计分、MMR 多样性、权重配置切换两组结果不同、空意图兜底）。
6. 维护 `docs/feature-tree.md`（功能树：模块 → 文件 → 职责 / 公开接口 / 依赖 / 配置入口 / 测试命令）。
7. **禁止"AI 味"**：
   - 不要任何 emoji（✨🎯🔥💬🚀等一律不要），不要星星/魔法棒/闪光/机器人图标，不要紫粉渐变霓虹、玻璃拟态光斑、发光阴影。

## 1. 视觉风格：模仿 Bonjour!（Bonjour 名片社交 App）

Bonjour 风格要点（你可以用 `--search` 查 Bonjour App / bonjour.bio 的截图确认）：
- **大面积纯白/暖白背景**（#FFFFFF / #FAFAF7），**纯黑大字号标题**（字重 700–800，标题字距略收紧），信息层级靠字号和留白，而不是靠颜色。
- **个人名片像一张实体卡片**：大头像（圆形或圆角方形）、名字超大、一句话简介、标签为浅灰底小胶囊（#F2F2F0，文字 #333）；卡片圆角 20–24px，阴影极轻（`0 1px 2px rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.04)`）或只用 1px #EEE 描边。
- 点缀色**只用一种**明亮色：建议 Bonjour 式的亮黄 `#FFD84D` 或活力橙 `#FF5A1F`（二选一，做成配置主题；默认亮黄用于高亮块/选中态，黑色用于主按钮）。主按钮：黑底白字胶囊。
- 卡片内容有"杂志感"：照片质感头像、实拍风活动封面、少量手写/贴纸感的小元素可以有，但要克制。
- 动效：轻、快（150–250ms），卡片 hover 只上移 2px + 阴影略加深；推荐结果依次淡入。
- 整体参考气质：Bonjour + Read.cv + Airbnb 的克制与高级感。

## 4. 推荐引擎（`src/core/matcher.js`，权重从 `src/config/matching.js` 读取）

```
Score(A,B) = 100 × Σ w_i·f_i × MutualBoost
f: needAB 0.30（A 意图 vs B 公开字段）, needBA 0.20（B 意图 vs A 本场公开字段）,
   complement 0.15（A.offer ↔ B.seek 供需对齐表）, common 0.12（双方都公开字段的 Jaccard）,
   reach 0.10（已签到 1 / 已报名 0.6 / openToChat 加分）, quality 0.08（公开字段完整度）, fresh 0.05（已见过/已互加降权）
MutualBoost = 1 + 0.15 × min(needAB, needBA)
Top5 用 MMR 重排：λ·Score − (1−λ)·max Sim(B, 已选)，λ=0.75（配置）
```
- 语义相似用"关键词 + 同义词表"（`src/config/synonyms.js`，如 投资人≈VC≈投资经理≈基金；供应链≈量产≈制造）。
- `parseIntent(text)` 把一句话解析为 `{seekRoles, seekIndustries, offer, city}`。
- **隐私**：B 只使用其本场所选版本 `visibleFields` 内的字段，隐藏字段绝不进入打分与理由文本（测试必须覆盖）。
- `reason(A,B,factors)` 用模板生成一句话理由 + 破冰话题，模板放 `src/config/reasons.js`，只引用公开字段。
- 返回每个因子的分值，供 UI 展示。
